# Практическая работа №33. Формы и валидация

Форма регистрации на Vue 3 (Composition API): `v-model`, валидация на клиенте, отправка через axios без перезагрузки страницы.

> Валидация учебная. В реальном проекте данные всегда нужно проверять ещё и на бэкенде.

## Структура

```
src/
  pages/
    RegistrationPage.vue  - форма регистрации: разметка, валидация, отправка, стили
  App.vue                 - <RegistrationPage />
  main.js
```

## Что сделано

- Поля: имя, email, пароль, подтверждение пароля (`v-model` + `reactive`)
- Проверки:
  - имя - не короче 2 символов
  - email - формат `что-то@что-то.что-то`
  - пароль - не короче 8 символов, строчные и заглавные буквы, цифры и спецсимволы
  - подтверждение - не пустое и совпадает с паролем
- «Живая» валидация: ошибка появляется, когда уходишь с поля (`@blur`), и обновляется при вводе (`@input`) - исчезает сразу, как только ошибку исправили
- Отправка через `axios.post(...).then(...).catch(...)` на `https://jsonplaceholder.typicode.com/users`
- Разные сообщения об ошибках:
  - ошибка сервера (есть `err.response`): 5xx - «Ошибка на сервере», 4xx - «Сервер отклонил запрос»
  - ошибка сети (есть `err.request`, но нет ответа) - «Ошибка сети: нет связи с сервером»

## Что проверить

1. Нажать «Зарегистрироваться» с пустой формой - под всеми полями ошибки
2. Ввести 1 букву в имя и перейти в другое поле - появляется ошибка; дописать букву - ошибка исчезает
3. Пароль `abcdefgh` → просит заглавную букву, `Abcdefgh` → цифру, `Abcdefg1` → спецсимвол, `Abcdef1!` - подходит
4. Правильная форма - зелёное сообщение с ответом сервера
5. Ошибка сети: DevTools (F12) → Network → Offline и отправить форму
6. Ошибка сервера: поменять `API_URL` на `https://jsonplaceholder.typicode.com/wrong-url` - сервер ответит 404
